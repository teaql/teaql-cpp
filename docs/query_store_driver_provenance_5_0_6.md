## Evidence collection and failures

The development replay uses one explicitly owned target and child temporary
directory. An owned adaptation of the existing reproducer only locates the
repository and retains raw input hashes and Context files. It does not rewrite
observer algorithms, source inputs or expected results. Its exact source must
match the reproducible adaptation of the repository script.

The [initial attempt](parity/query_store_driver_execution_5_0_6.json.gz) stops
before Rust observer compilation because the owned Python script cannot resolve
repository helpers. The corrected replay supplies explicit repository module
paths; the failed receipt remains unchanged and is not a runtime defect.

The [successful replay](parity/query_store_driver_execution_final_5_0_6.json.gz)
retains all raw outputs, exact input hashes, five actual extraction outputs,
the original prepared project and Cargo metadata. It records 466 reference Rust,
manifest and lock files. The full Context view preserves all 67 original runtime
source, test and vector files, appends the exact existing observer, and derives
its manifest from actual dependency metadata. Only the two previously reviewed,
disabled external-exporter development dependencies are omitted; this does not
claim acceptance of external telemetry integrations.

The [source validator](../scripts/verify_query_store_driver_contracts_5_0_6.py)
checks these bindings without compiling Rust during routine CTest. The
[binding receipt](parity/query_store_driver_bindings_5_0_6.json.gz) distinguishes
the 36 Context observations from additional corpus rows and the two appended
tests from original embedded tests. The
[29 controls](parity/query_store_driver_controls_5_0_6.json.gz) reject replaced
extractions and drivers, reduced Context substitutions, changed dependency
identities, partial outputs and Boolean/number confusion. Two controls use actual
historical lockfiles whose identities differ from the locked reference.

## Scope boundaries

Complete cache/pagination source bodies and the full Context supplement retain
their separate roles. Live timestamps are checked with actual clock brackets;
they are not replaced with fixed values. Source poisoning/Send/Sync behavior
retains the approved C++ Context threading adaptation. C++ results remain borrows
or explicit destination copies, with two allocation domains.

No external cache integration, third-party deployed dependency, production C++
implementation or generated artifact is added. Complete generated pagination,
entity-service miss/lock/recheck/build orchestration, metadata grammar, protected
execution and remaining source/observer/dependency/normalization provenance
retain their own acceptance requirements.
