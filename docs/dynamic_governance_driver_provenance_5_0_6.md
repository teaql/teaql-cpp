The [dedicated source project](../tests/parity/rust_dynamic_governance_source_5_0_6/Cargo.toml)

registry versions and checksums. The only added local package is the archived

School domain library. The generated dynamic-JSON crate is copied with its

The source replay copies 73 input files and builds the seven complete targets
with `--offline --locked --bins`. Actual Cargo metadata must contain exactly
the declared project, generated crate and archived local packages. Every
registry name/version/source/checksum must belong to the reference lock.
All copied and archived bytes are checked after execution. Rust targets and
child scratch files use one owned temporary directory; shared downloads and
stable native profiles are retained.

Seven input recipes call existing pure input functions. Two older generators
construct inputs inside `main`; their exact assignment and extension statements
are selected by source and AST hashes. These statements are executed unchanged,
without argument parsing or generation commands. The complete resulting lists
must equal the retained corpus inputs, in order. No expected result is rewritten.

The [shared generated-model verifier](../scripts/generated_driver_provenance_5_0_6.py)
uses the unchanged archive replay mechanism. Its registry describes local
packages, generated provenance and input recipes, allowing subsequent source
cohorts to reuse the same mechanism. Routine CTest validation uses retained
source execution evidence and does not rebuild Rust. Each existing native
comparison requires this cohort's source fixture. Receipt mutation controls
run serially to avoid competing with timed native probes.

Scope follows each retained observer. Definition/storage/graph checks do not
claim physical persistence. Root-query enhancement uses the retained native
School carrier, not a newly generated complete C++ School SDK. The policy-denial
matrix checks the whole immutable change plan and pending intent; it does not
perform SQL after denial. Save matrices execute actual SQLite persistence,
versions, policy approval/denial, rollback and committed audit-delivery failures.
Safe audit/SQL observations omit the original observer's nondeterministic clock
and timing fields. Graph diagnostics retain the original single-field fixture
that avoids randomized map ordering. Other values, keys, errors, SQL, intent,
versions and audit projections remain exact.
