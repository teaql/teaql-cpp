# G07 predicate and projection acceptance

G07 is qualified for the complete locked source-selected field interface, with
the documented C++ ownership/naming and native-extension dispositions. All twelve
requirements in the [matrix](predicate_projection_requirements_5_0_6.md) are
addressed. The prior capability entry and open questions remain unchanged in the
[pre-acceptance archive](parity/predicate_projection_pre_acceptance_5_0_6.json.gz).
This decision does not complete P4 or the full generator goal.

The review covers all 63 complete field-template methods and their guards,
canonical field/operator/function routing, literal defaults, source metadata
identities and independent projections. Original source spans and current native
generation/construction bodies are retained in the
[complete source review](parity/predicate_projection_source_review_after_alias_fix_5_0_6.json).
Body review is combined with actual original/native observations; method counts
and generated inventories are not used as acceptance proof.

The accepted evidence includes the operator/independent-criteria matrix,
Value/membership input and scalar branch matrices, text/function/alias/removal
execution, actual float/reference SQL, complete selection state and typed
optional/temporal/Boolean SQLite execution. The final review reproduced a real
reserved-name alias defect, corrected misleading camelCase result keys in Assist,
and restored the separate query/descriptor identities that produce authentic
source keyword failures. The [alias contract](query_alias_contracts_5_0_6.md)
records that implementation and its complete 660-case source comparison.

The final regression selection passes **15/15 native checks**, the new imported
checks **2/2**, selected ASan/UBSan checks **2/2** with leak scanning disabled,
and compiler controls **7 positive / 12 negative**. Java passes **65/65**.
All **24 ordinary workspaces / 288 files**, **50 existing contract SDKs** and the
new complete keyword fixture strictly reproduce. Source/template checks and
canonical module consumer verification pass. The
[acceptance record](parity/predicate_projection_acceptance_5_0_6.json) binds the
requirements and terminal evidence.

Source-native default aliases remain literal protocol data, and application
methods keep their established camelCase/C++ keyword escaping. Existing typed
native conveniences beyond the source branch are explicitly recorded extensions;
they do not turn genuine Rust refusals into acceptance. Unsupported functions,
invalid SQL aliases and source keyword metadata failures remain visible. Checked
Context borrows and explicit destination copies replace Rust ownership without
extending Context lifetime or adding an execution path to field adapters.

The earlier broad open questions include responsibilities shared with G06,
G08-G10 and G12-G17. Their general-query/raw trust, relationship/aggregate,
page/stream, dynamic storage, complete Assist and final composed policy/privacy/
trace/configuration requirements remain active under their original capabilities
and phase exit criteria. This decision closes the field-interface responsibility
through its complete source branches and semantic evidence; it neither removes
those requirements nor establishes their full integration. No full-suite,
external-provider, GPU or physical-router acceptance is inferred.
