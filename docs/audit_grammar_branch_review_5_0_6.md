## Source contract and observed defect

The unchanged `teaql-macros/src/attr.rs` parses attribute values as `syn::Expr`.
The reference deliberately ignores nonliteral audit-length expressions. Parsing
must nevertheless consume a valid expression so that later entity, table,
service, mask, indexed-layout and audit-length settings retain their effects.
An ignored nested-meta parse error can instead stop the callback after earlier
settings have already taken effect. These outcomes are compared independently.

The locked `syn` 2.0.118 `expr.rs::atom_expr` dispatches
`builtin # identifier (opaque tokens)` to `expr_builtin`, which returns
`Expr::Verbatim`. The preceding Java adapter lacked this dispatch. The
[initial comparison](parity/audit_grammar_branch_initial_5_0_6.json.gz)
retains 45 actual metadata differences, including lost later overrides. All
8,252 preceding source observations remain unchanged.

The repair adds one branch to the existing Java expression cursor, using its
identifier, trivia and token-group parsing. A plain `builtin` expression still
uses ordinary path parsing; malformed builtin syntax retains the source's
partial-effect behavior. No runtime dependency or C++ implementation changes.
