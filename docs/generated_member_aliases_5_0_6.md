## Reproduction

```bash
set -e
source scripts/toolchains/activate.sh
python3 scripts/regenerate_decoder_bindings_5_0_6.py \
    --record /tmp/generated_member_alias_reproduction_new.json.gz
python3 scripts/verify_generated_member_aliases_5_0_6.py --profile native \
    --stage build --record /tmp/generated_member_alias_native_new.json.gz
python3 scripts/verify_generated_member_aliases_5_0_6.py --profile native \
    --stage test --record /tmp/generated_member_alias_native_new.json.gz
```

Use `modules_native` or `sanitize` with fresh record paths for their selected
gates. Build completion is checked before any execution, and a final successful
no-work build guards each result. `--apply` on the regeneration tool is only for
the reviewed initial decoder-binding migration, not arbitrary generated changes.
If the system temporary filesystem lacks room for PCH files, set `TMPDIR` to
suitable task-owned storage before the test stage; this checkpoint's full retry
used `/dev/shm`. Preserve failed receipts and select a fresh record for a retry.
