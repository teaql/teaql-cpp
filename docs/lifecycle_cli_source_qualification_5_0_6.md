## Resource and Info adapters

Rust resource replacement drops the old Box immediately. Managed C++ arena
objects remain alive until Context close. The established ownership comparison
checks every action's Rust drop count, the C++ deferred-drop count, created/final
destroyed totals and rejection of get/copy through expired native borrows.
Wrong-type typed/named shadowing and byte-exact keys/payloads remain semantic
observations. Raw language-specific missing-type names remain separate diagnostics.

The source gate executes the **unchanged ownership-loop AST** from the actual
comparator. It does not maintain a second ownership algorithm. The new shape
guard requires the exact known source/native ownership fields before applying
that contract. Semantic objects compare in full.

Rust's sample observer records `INFO`, the authentic generated module target and
the message. C++ dispatches through its Context-owned sample Info sink. The
existing projection validates source level/target and compares exact ordered
messages plus the complete underlying outcome. Unknown root or log-record
fields are rejected before projection. Neither adapter permits a source payload
to disappear through an unreviewed field.
