The installed `entity_constructor_helpers_rust_parity` comparison now
requires a source fixture. This checkpoint rebuilt the original Rust observer
from the locked 5.0.6 runtime and unchanged generated inheritance entities in
a task-owned Cargo target. Its 512 complete outputs match the frozen corpus;
fresh C++ execution also matches **512/512** outputs. The matrix covers five
models, six inherited or child scalar paths, new and row construction,
updates, overlays, snapshots, copies, and two controlled wall clocks.

The [source contract](../tests/parity/entity_constructor_cli_contract_5_0_6.json)

[fresh original execution](parity/entity_constructor_cli_original_execution_5_0_6.json.gz),
historical terminal, current comparator, C++ observer, fixed-clock source,

closure, complete input matrix, the original model and all 43 generated files.

hashes, source hashes, and successful comparison. Its task-owned Cargo target

split into per-model CTests. Its other recorded file hashes remain current;
the current comparator is pinned separately. The terminal's producer
implementation hash describes its earlier checkpoint and is not promoted to
a current generator-source claim.
