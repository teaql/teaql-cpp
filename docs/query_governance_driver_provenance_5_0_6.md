The shared verifier gains three explicit input/source forms:

- An input expression is evaluated from the exact generator assignment AST in
  its original module namespace. This preserves concatenation of construction,
  physical-execution, nullable and error-case builders, in source order.
- A retained input fixture supplies a complete declared list. Entry lookup uses
  only `inputs` from its initial comparison receipt; that receipt's old C++
  failures and original results are not used as new expected values. A negative
  control substitutes its `original` member and must fail the input binding.
- Corpus source locators explicitly select the runtime repository or project
  root. Entry lookup's historical project manifest, lock, helper and SQL hashes
  are project locators. They remain separate from the actual new compiled
  project, dependency metadata and lock. Runtime source locators retain their
  previous default interpretation.

SQL fixture hash dictionaries are also checked at their declared fixture root.
The complete generated crates and runtime archive are copied into one owned
temporary build tree. Registry dependencies must preserve reference versions
and checksums; actual Cargo metadata must contain exactly the declared local
packages and target paths. Source builds use `--offline --locked --bins` with
debug assertions retained. Original collector projects and their locks remain
unchanged.

Observer scope remains explicit. Aggregation and facet corpora include actual
SQLite execution and provider failures alongside complete query construction.
They do not independently establish every relationship aggregate, roll-up,
bootstrap or protected configuration. Cache observations wrap the original
in-memory aggregation cache and retain exact callback keys, requested ages,
hit/put values and cumulative SQL logs. Its original four short real-clock
expiry cases remain unchanged. Entry lookup observes missing-service execution
boundaries rather than successful database access. No result normalization or
case reduction is introduced.
