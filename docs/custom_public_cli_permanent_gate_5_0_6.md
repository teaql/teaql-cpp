## Source and dependency enforcement

The validator pins both immutable execution receipts by file hash. It checks
the original Debug/overflow profiles, observer paths, return codes, complete
output counts and exact serialized input identities. The generated manifest
and compiled Cargo lock retain their exact identities. All eight local package
paths must point into the original owned archive or SDK/project; duplicate local
identities and registry packages outside that lock reject.

Current references must be clean and match the locked runtime/generator
commits. A fresh Git archive matches the original archive hash and all **610
file hashes**. Current project/model/fixture bytes match the retained **72-file**
source map under two explicit role rules:

- The initialized-cache comparator may be the exact original or the exact
  prepared two-condition repair. Inverting that repair must reproduce the
  complete original file hash. Any other code change rejects.
- The capability ledger supplies baseline metadata to the collector; it is not
  a Rust compiler input. Its runtime/generator keys must stay locked. Later
  status-only ledger updates do not alter the archived Rust execution.

Seven local verifier helpers are also hash-bound. The native binding artifact
must retain its raw stream identities, source-execution link, executable hashes,
four complete result groups and all 31 original boundary controls. Fresh native
execution uses the original observation contract directly and checks each
executable hash before and after the run.

## Actual corruption controls

All **66 controls** pass: **62 intended rejections** and **four permitted cases**.
They reject numeric substitutes for Boolean completion/Debug/exit flags, changed
baselines, driver identities, manifests/locks, package paths and dependency
identities; artifact/hash drift, false fresh-Rust claims and altered raw streams;
missing/extra rows, fields, inputs and JSONL records; native/source JSON type
changes; and undeclared or incorrectly inverted comparator edits.

The permitted cases cover valid retained evidence, independent cache diagnostic
text, the original comparator and its exact approved repair. Tests execute the
actual validator methods on explicit copies; no source worktree, immutable
artifact or committed corpus is mutated. These control runs do not execute Rust
or C++ observers.
