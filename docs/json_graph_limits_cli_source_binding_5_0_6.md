# JSON graph-limit CLI source binding, Rust 5.0.6

The installed `json_graph_limits_rust_parity` comparison now requires a
source fixture. A fresh Rust build executed the original JSON hydration
observer on all 11 large graph boundary and view cases. Its complete outputs
match the frozen source corpus; fresh C++ execution with the large-fixture
entry also matches **11/11** outcomes. The cases distinguish node-limit
rejection from unknown fields, invalid relation items and conflicting values
for one entity identity.

The [source contract](../tests/parity/json_graph_limits_cli_contract_5_0_6.json)
reconstructs 610 original runtime source-file hashes from the exact Rust Git
archive and verifies the nine append-only private test access bridges. It
pins the original observer, Cargo manifest and lock, reference-seeded
dependency closure, complete 11-case input matrix and frozen outputs. The
existing derived source fixture was verified against all original and
compiled file hashes before the fresh build and was preserved because it
predated this task.

The [fresh original execution](parity/json_graph_limits_cli_original_execution_5_0_6.json.gz)
retains all 11 outputs, source and executable hashes, and the successful
Rust/C++ replay. Its task-owned Cargo target was removed. The source fixture
can verify the archive directly from the locked Git revision without
requiring that pre-existing derived source tree.

The [15 negative controls](parity/json_graph_limits_cli_controls_5_0_6.json.gz)
reject altered large inputs, original outcomes, driver hashes, archive size,
CTest commands and fixture removal. The
[native receipt](parity/json_graph_limits_cli_native_5_0_6.json.gz),
[selected CTest receipt](parity/json_graph_limits_cli_selected_ctest_5_0_6.json.gz),
and [complete selected log](parity/json_graph_limits_cli_ctest_log_5_0_6.txt.gz)
record five passing tests, including the installed comparison and Context
self-test. The temporary JUnit file was removed. The
[milestone receipt](parity/json_graph_limits_cli_milestone_5_0_6.json.gz)
records the bounded result and artifact hashes.

After the repaired full native epoch, the result comparator's final equality
check was made explicit so `python -O` cannot skip it. The
[permanent control receipt](parity/json_graph_limit_optimized_permanent_controls_v2_5_0_6.json.gz)
retains the 15 source/CTest substitutions and four complete/corrupted
11-record executions plus two changed-baseline refusals under ordinary and
optimized Python. The current source
contract pins both changed Python files; seven selected CTests across this and
the derived-query comparator pass. The earlier complete native epoch predates
these two comparator edits.

The [incremental dispatcher lookup](parity/json_graph_limits_cli_remaining_dispatchers_5_0_6.json.gz)
retains 222 rows: 155 of 160 comparison locators have source contracts, with
five remaining. The 1,046 CTest registrations are enumeration. The
[previous-input delta](parity/json_graph_limits_cli_previous_input_delta_5_0_6.json.gz)
rehashes earlier protected inputs against the current checkout.

This change binds JSON graph boundary evidence and test admission. It does
not establish full generated JSON or graph Save acceptance, and changes no
runtime, generator, generated SDK, original Rust method, C++ graph algorithm,
or Context ownership. Complete G13/G14/G17, GP13/GP16, AP02, and P0–P7
remain open. The original source-binding checkpoint did not run sanitizer,
MIPS, module, GPU, physical-router or full-suite gates. The later complete
native epoch and post-epoch selected comparator gates are recorded above.
