# Generated relation-analysis CLI source binding, Rust 5.0.6

The existing generated relationship-analysis CTest command now requires a
source contract fixture. Its frozen corpus retains **7,122 original Rust
observations**. Of these, **6,576** compare to current C++ under the previously
documented single Line descriptor Debug spelling adapter. The remaining
**546** use separate, explicit C++ expectations under the
[user-approved quoted-FK exception](quoted_fk_compatibility_exception_5_0_6.md).
Original Rust observations are never rewritten, and the exception cases are
never reported as strict Rust matches.

The [contract](../tests/parity/relation_analysis_cli_contract_5_0_6.json)
pins the locked runtime and generator commits, immutable corpus, approval
manifest, original observer and the [source failure witness](parity/relation_aggregate_quoted_fk_source_failure_5_0_6.json).
The approval manifest pins all 546 exact case indices and its supporting
evidence. The binding verifies the current generated Rust library and semantic
model hashes, SQLite fixtures, first independent failure witness and actual
CTest command before running the current native probe. It rejects any new or
relabelled exception case.

The [15 controls](parity/relation_analysis_cli_controls_5_0_6.json.gz) reject
missing or changed source results, changed C++ exception expectations, scope
changes, swapped receipts and altered CTest commands. The
[fresh native receipt](parity/relation_analysis_cli_native_5_0_6.json.gz)
records **6,576** source comparisons and **546** approved C++ results. The
[selected CTest receipt](parity/relation_analysis_cli_selected_ctest_5_0_6.json.gz)
passes **4/4** checks: the actual comparison and three source-binding gates.
This reuses retained Rust observations; no new Cargo execution is claimed.

The **1,007** registered tests are an inventory, not a full-suite run. The
[static lookup](parity/relation_analysis_cli_remaining_dispatchers_5_0_6.json.gz)
maps **137/160** comparison commands to source contracts, leaving **23** for
review. The [preceding-input comparison](parity/relation_analysis_cli_previous_input_delta_5_0_6.json.gz)
rehashes 11,694 earlier build and qualification inputs; only this CMake
registration and the two qualification ledgers differ. The historical analysis
and exception documents were also updated to state the current approval; they
are outside that input snapshot. Existing runtime functions, comparison algorithm, producer implementation
and generated SDKs are unchanged. Complete G13/G14/G17, GP13/GP16, AP02 and
P0–P7 qualification remains open. No new sanitizer, MIPS, imported-module,
GPU or physical-router verification is claimed.
