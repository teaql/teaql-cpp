[constant-function resolution](ap02_const_function_calls_5_0_6.md) now execute
together in complete generated School domains. They retain the existing
observer's `primitive_` relation prefix and JSON property as observation protocol

assertions become unconditional checks through the existing retained AST

launcher/environment adaptations are retained for all 41 engine subprocesses.

Each records three matching original/C++ descriptors, twelve matching Save
pairs and twelve actual ordinary/debug file publication cases. Across both

The Save observer checks root/child writes, rollback after a later failure,

lengths. Ordinary SQL stays masked; the exact permission and enabled debug

Generated Checker assembly is exercised through the unchanged domain/runtime
setup. These observations do not add an independent custom Checker/Fix matrix.
They extend the configuration/runtime join without replacing the existing G02,
GP07 or complete G13/G14/G17 obligations.

The ordinary and optimized readers accept both completed execution receipts
and reject nineteen corruptions per configuration per mode. Sixteen inherited
