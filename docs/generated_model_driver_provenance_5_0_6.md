and [dedicated project](../tests/parity/rust_generated_model_driver_source_5_0_6/Cargo.toml)

execution/failure each keep their complete retained matrices.

Nine complete generated packages are compiled: candidates, Checkers, numeric
constants, constant catalog, dynamic JSON, ordinary inheritance, graph

is also compiled unchanged.

original full crates have recorded compilation defects. The dedicated project

as an explicit Cargo library target, compiling its original generated entity

supplies reference-locked dependencies. This is entity-level source evidence,
not acceptance of the broken full request/runtime scaffolds. No generated
source file is repaired or hand-edited.

must contain exactly the project, six archived TeaQL packages, nine generated
packages and archived School. The original library source path and target kind
must match the actual compiled metadata.

selection is reused. The [input selector](../scripts/generated_model_driver_inputs_5_0_6.py)
