# Composed-query and graph-save CLI source binding, Rust 5.0.6

Two existing CTest comparisons now require a source contract fixture. The
retained original Rust executions cover **5,472 complete observations**:
4,864 composed queries and 608 keyword-relationship graph saves. Their paired
receipts contain every original and C++ result; the current native probes again
match every original result. This binding reuses prior Rust execution and does
not claim a new Cargo run.

The [contract registry](../tests/parity/composed_graph_cli_contracts_5_0_6.json)
pins the locked runtime and generator commits, complete corpora, paired raw
outputs, terminal acceptance records, source adapters and actual CTest
commands. The composed-query terminal record names the exact corpus and paired
receipt hashes in its source map; the graph-save terminal names both in its
artifact map. Current original-driver, dependency and generated-model
identities must match the corpora before either native command runs.

The composed-query matrix crosses typed and raw shapes, Policy and request
intent, safe diagnostics, pagination choices and inherited models. The source
binding also checks that invalid intent produces its recorded panic before
Policy, SELECT and logs, and that disabled logging emits no records. The graph
save matrix retains read, create, update, delete and mixed relationship work,
Checker and Policy outcomes, optimistic conflicts, database triggers, audit
delivery and ordered safe SQL observations within its existing observer
boundary. Exact full JSON comparison does not turn these focused matrices into
whole application or provider acceptance.

The [15 controls](parity/composed_graph_cli_controls_5_0_6.json.gz) reject
changed or missing source output, false comparison success, substituted
receipts and altered CTest commands. The
[fresh native receipt](parity/composed_graph_cli_native_5_0_6.json.gz) records
all 5,472 matched results. The
[selected CTest receipt](parity/composed_graph_cli_selected_ctest_5_0_6.json.gz)
passes **5/5** checks: both actual comparisons and the three binding gates.
The **1,004** registered tests are an inventory, not a full-suite run. The
[static lookup](parity/composed_graph_cli_remaining_dispatchers_5_0_6.json.gz)
maps **136/160** comparison commands to source contracts, leaving **24** for
review. The [preceding-input comparison](parity/composed_graph_cli_previous_input_delta_5_0_6.json.gz)
rehashes 11,694 earlier inputs; only this CMake registration and the two
qualification ledgers differ.

The current native validator disables the built-in LogManager endpoint and
sensitive plaintext opt-in, matching the existing comparison boundaries.
Existing runtime functions, comparison algorithms, producer implementation and
generated SDKs are unchanged. Complete G13/G14/G17, GP13/GP16, AP02 and
P0–P7 qualification remains open. No new sanitizer, MIPS, imported-module,
GPU or physical-router verification is claimed.
