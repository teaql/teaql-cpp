## Original source and observer scope

Each epoch checks the same complete **610-file source archive**. A disposable
view preserves all **67 original runtime source, test and vector files**.
Selected observer modules are appended to seven existing source files in the
default epoch and three in the variant epoch. Original production and test
prefixes remain byte-identical.

Each view is compiled once with `--offline --locked --no-run --lib`. Compiler
artifacts verify Debug assertions, arithmetic overflow checks and the test
profile. Every selected Rust test executes in its own process with `--exact`
and one test thread, preserving the earlier per-program static-state boundary.
This is not a run of every original Rust test.

The existing private-view recipe omits only the two disabled external-exporter
development dependencies. Their core SPIs remain in scope. Full reference
registry name/version/source/checksum checks remain active.

Fixture paths and input-file paths are rebound into owned copies. Two
appended graph-planner helper modules receive distinct names so their variant
tests can coexist. The receipts retain every original/adapted observer and an
invertible relocation recipe. Validation permits only these path and helper
namespace substitutions; original runtime bodies are unchanged.

## Graph matrix admission repair

The preceding graph-planner and legacy comparison loops used `zip` without
requiring complete equal input/expectation lengths. Truncated expectations,
extra records and partial matrices could return success. Provenance flags also
accepted numeric values through Python truthiness.

The [actual preceding CLI controls](parity/graph_observation_admission_before_5_0_6.json.gz)
reproduce **39 false acceptances** across the planner, legacy and extended
legacy routes. Malformed inputs that already raised incidental exceptions are
not included in that count.

The [installed controls](parity/graph_observation_admission_installed_5_0_6.json.gz)
pass **60/60** checks. The full qualified matrices remain 896 planner inputs,
72 basic legacy inputs and 284 extended legacy inputs. Empty, partial, unequal
or incorrectly typed matrices fail before a probe executes. This controlled
observer test isolates Python admission; it does not execute Rust or C++.

## Source and native binding

The permanent source validator checks both execution epochs, original archive
and runtime prefixes, locks, compiler artifact, original test selectors,
appended observer recipes and every raw marker-framed record. The registry
fingerprints **81 observer/helper inputs**. It also checks actual CTest commands,
including each `--original` selection and the attachment-observation probe mode.

The [native binding](parity/custom_program_native_binding_current_5_0_6.json.gz)
matches all **8,098/8,098** outputs. Legacy graph requests retain the declared
nonempty `bound_intent` input addition. Relation enhancement compares each
source `result`; the ID-set continuation compares each source `expected`.
These explicit envelope projections preserve complete business results and
ordering; they are not whole-envelope equality claims.

An initial native adapter omitted `--attachment-observations` and failed while
decoding ordinary unit-test output. That attempt is not a passing binding.
Its [compact diagnosis](parity/custom_program_native_protocol_failure_5_0_6.json.gz)
retains the missing-mode cause; the actual comparer, registry and validator
require the corrected mode.

The [source controls](parity/custom_program_source_controls_5_0_6.json.gz)
pass **42/42**, including complete positive environments and rejections for
wrong profiles, altered source prefixes, incomplete programs, unapproved
observer edits, swapped same-script datasets and omitted native arguments.

The [installed native selection](parity/custom_program_installed_gates_5_0_6.json.gz)
passes **33/33** checks: all 29 comparison invocations plus admission, source,
corruption and native-binding gates. Every comparison requires the source
fixture. Configure succeeds and the native build reports no work. The registry
contains **949 tests**; a full 949-test execution is not claimed.

This proof covers graph plans/outcomes, explicit save scopes, relationship
enhancement and attachment, resolved execution and private memory programs.
It does not replace complete protected publication, all generated model
configurations or broader governance integration. No new C++ Release,
