# Current narrow-integer source registration, Rust 5.0.6

The current narrow-integer comparison now requires its complete original-source
qualification before it executes. Native CTest installs the prerequisite and
canonical module bindings project it into the imported frontend. Cross builds
retain the existing comparison and emulator without acquiring a dependency on
host-native qualification artifacts. This changes development gates only;
production C++ and the independent producer remain unchanged.
