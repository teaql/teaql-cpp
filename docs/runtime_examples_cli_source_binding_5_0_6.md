The installed `runtime_examples_rust_parity` comparison now requires a source
fixture. A fresh build of the retained Rust observer ran the locked example
models and original business operations for the schema/CRUD and relation/graph
scenarios. Both whole business outputs match the 5.0.6 corpus and fresh C++
example runs. The two ordered SQL provenance arrays, containing **34 entries**
in total, match the retained original record.

The observer supplies required query comments at caller entry. This result
does not claim that the unchanged stock Rust example binaries accept missing
request intent. The [source contract](../tests/parity/runtime_examples_cli_contract_5_0_6.json)

hashes, current C++ example sources, the complete business/SQL records, and
a dedicated 132-package reference-seeded Cargo closure. The older shared
field-layout lock is historical and is not used for this source closure.

retains both complete outputs, both SQL arrays, and build/source hashes. Its
one-off Cargo target was removed. The [15 negative controls](parity/runtime_examples_cli_controls_5_0_6.json.gz)
reject changed business inputs/outputs, SQL order and cardinality, original
source hashes, CTest commands and fixture removal. The [native receipt](parity/runtime_examples_cli_native_5_0_6.json.gz)
and [four selected CTests](parity/runtime_examples_cli_selected_ctest_5_0_6.json.gz)
cover the installed comparison and source fixture.

now maps **160/160 installed comparison locators**. The **1,058** CTest
registrations are enumeration, not full-suite or generator acceptance. This
source binding changes no runtime, generator, generated SDK, C++ algorithm or
