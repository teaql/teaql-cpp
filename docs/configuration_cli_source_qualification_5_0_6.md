## Permanent source and selection checks

The source registry binds every actual CTest comparator, `--case`, native binary
and model variant to its original project and complete corpus. All thirty
comparisons retain the canonical recipe prerequisite and additionally require
`configuration_cli_source`. Source preparation and validation do not modify the
Rust archive or generated files.

The permanent gates are `parity_configuration_cli_source_contracts`,
`parity_configuration_cli_source_controls` and
`configuration_cli_source_rust_parity`. The existing recipe and admission gates
keep their separate responsibilities. No result adapter is introduced.

Two controlled substitutions found that the initial source verifier did not
reject a forged domain-library `test` profile, including numeric zero. The
[preceding controls](parity/configuration_cli_source_profile_before_5_0_6.json.gz)
retain those two false acceptances as diagnostic evidence. The verifier requires
literal `false`
for library test mode. Original recorded artifacts already satisfy this rule;
input selection and all original compiled sources retain their bytes.

The [source controls](parity/configuration_cli_source_controls_5_0_6.json.gz)
reject all **63 substitutions**, including the two forged library profiles, with
the valid complete source and CTest selections accepted. The
[installed native receipt](parity/configuration_cli_source_installed_native_5_0_6.json.gz)
passes **33/33 checks** with no failures, errors or skips and retains full JUnit
and CTest logs. Source controls execute independently through the installed
control program with its report option.

The native receipt explicitly reuses earlier raw native vectors under unchanged
executable identities and matches them against the fresh original results. It
also verifies new current native execution through all thirty comparisons and
the complete source/native gate. Reused raw vectors retain their earlier epoch.
Registration is **967**, not a full 967-test execution. Pinned formatting of
1,809 handwritten files and its check pass; the affected native build has no work.
Reference, path and generator guards pass. No fresh sanitizer, MIPS or physical
device run is claimed.
