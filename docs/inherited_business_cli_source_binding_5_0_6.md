# Inherited Business-ID CLI source binding, Rust 5.0.6

The installed `inherited_business_extensions_rust_parity` comparison now
requires a source fixture. A fresh Rust build executed the original generated
Checker, entity, and runtime methods through the previously specified child
binding bridge. Its complete 450 outputs match the frozen source corpus;
fresh C++ execution also matches **450/450** outcomes. The matrix covers five
models, custom inspect/deny/fix logic, Policy allow/deny, create/update paths,
SQLite trigger and optimistic failures, ordered Fix evidence, and audited
Save outcomes.

This is **adapted-source execution**. The original generated domain does not
compile untouched: the bridge adds four child imports and copies the original
parent Business-ID slot body onto each flattened child carrier, with one
tuple-field visibility change. It does not rewrite Checker or Save method
bodies. Untouched producer artifact acceptance remains false. The
[source contract](../tests/parity/inherited_business_cli_contract_5_0_6.json)
recomputes every adapted file hash from all 43 original generated files and
the pinned bridge recipe, without needing a retained derived build tree. It
checks the reference-seeded Cargo dependency closure, historical source
boundaries, complete input matrix and Checker/Policy/Fix/Save counts.

The [fresh original execution](parity/inherited_business_cli_original_execution_5_0_6.json.gz)
retains all 450 outcomes, source and executable hashes, and the successful
Rust/C++ comparison. Its task-owned Cargo target and reproducible derived
bridge output were removed after capture. An
[initial environment failure](parity/inherited_business_cli_initial_env_failure_5_0_6.json.gz)
records that the first one-off observer call omitted the Business-ID test key;
the corrected replay used the same locked sources and inputs. The older
source and terminal receipts have one stale comparator hash after a CTest
split; their other recorded source hashes remain current.

The [15 negative controls](parity/inherited_business_cli_controls_5_0_6.json.gz)
reject altered source, matrix, outcomes, false untouched-acceptance claims,
CTest commands and fixture removal. The
[native receipt](parity/inherited_business_cli_native_5_0_6.json.gz),
[selected CTest receipt](parity/inherited_business_cli_selected_ctest_5_0_6.json.gz),
and [complete selected log](parity/inherited_business_cli_ctest_log_5_0_6.txt.gz)

lifetime contract. The temporary JUnit file was removed. The
[milestone receipt](parity/inherited_business_cli_milestone_5_0_6.json.gz)

The [incremental dispatcher lookup](parity/inherited_business_cli_remaining_dispatchers_5_0_6.json.gz)

This change binds evidence and test admission. It changes no runtime,
generator, generated SDK, original Rust method, C++ business algorithm, or

was run for this source-binding change.
